Client

💻 Customer  ·  📱 Driver  ·  🖥️ Admin  (Postman khi chấm)

🛡️API Gateway http://localhost:3000 · cổng duy nhất của hệ thống

  • Authentication: kiểm tra JWT (401)
  • Authorization: theo role (403)
  • Rate limiting (429)
  • Routing REST → gRPC
  • Đăng xuất: thu hồi token
  • Log · /health · /ready

🧱Redis (chỉ Gateway dùng)

  • Bộ đếm rate limit
  • Danh sách token đã thu hồi
  • Không lưu dữ liệu nghiệp vụ

🌐Hệ thống ngoài (giả lập)

  • Payment Provider: module trong payment-service, gọi ngay xử lý callback
  • Map: thay bằng công thức khoảng cách
  • Thông báo, SMS, OTP: lưu database và ghi log
