Client

🛡️API Gateway (cổng duy nhất mở ra ngoài)

  • Phân quyền theo role (→ 403)
  • REST → gRPC (định tuyến)
  • Giới hạn tốc độ (→ 429)
  • Ghi log, giám sát
  • /health · /health/services

🧱Redis (API Gateway DB)

  • Rate limiting
  • Cache token / danh sách thu hồi
  • Cache dữ liệu
