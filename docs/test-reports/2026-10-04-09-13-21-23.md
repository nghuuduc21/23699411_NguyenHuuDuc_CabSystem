```bash
docker exec auth-db psql -U cab -d auth -tAc "select string_agg(account_id::text, ',') from accounts where phone like '0399%' or phone like '0599%'"
docker exec driver-db psql -U cab -d driver -c "delete from vehicles where driver_id in (…); delete from drivers where driver_id in (…)"

```

`npm test` nay chạy file 01–10. File `04-health-degraded` trong đó dừng `rating-service` và `redis`; khi có người khác đang dùng hệ thống thì chạy `npm run test:nghiep-vu`.

Quy ước dữ liệu test, để không đụng seed:

| Dữ liệu | Dải | Dọn |
|---|---|---|
| Khách tạo mới | `0399` + 6 số ngẫu nhiên | Hook `after` xóa tài khoản và hồ sơ |
| Tài xế tạo mới | `0599` + 6 số ngẫu nhiên | Hook `after` xóa tài khoản, OTP, hồ sơ, xe |
| Biển số | `99T-` + 5 số ngẫu nhiên | Xóa cùng hồ sơ |
| Mã do API tạo | Luôn đọc từ response, không viết cứng | — |

Trạng thái seed sau khi chạy (đã kiểm bằng `psql`): TX1–TX4 `ONLINE` đúng vị trí seed, TX5 `OFFLINE` (10.825), TX6 `BUSY`, TX7 `PENDING`, TX8 `ONLINE`. Hồ sơ khách chỉ còn 1, 2, 9. Không còn tài khoản `0399…` hoặc `0599…`.

Để không đổi seed, một số AC được kiểm trên dữ liệu tạo mới. Dữ liệu tạo mới đi qua cùng nhánh code với dữ liệu seed:

| AC | Spec ghi | Đã kiểm trên | Lý do |
|---|---|---|---|
| AC-HS-04, 05, 10 | KH3 tạo hồ sơ | Khách mới đăng ký qua API | Nếu tạo hồ sơ cho KH3 thì KH3 không còn "chưa có hồ sơ" cho mục 11 phụ. AC-HS-03 vẫn kiểm trên chính KH3 (chỉ đọc) |

| AC-TX-15 | Từ chối TX7 | Hồ sơ tài xế mới nộp | Giữ TX7 `PENDING` cho dev-agent và mục 22 |
| AC-TX-13 | `total = 2` | `total` bằng số hồ sơ `PENDING` đếm trong database; TX7 đứng trước hồ sơ mới | Số hồ sơ chờ duyệt phụ thuộc người khác đang tạo |
